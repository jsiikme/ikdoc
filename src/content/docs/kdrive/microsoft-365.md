title: Microsoft 365
---

kDrive intègre **Microsoft Word, Excel et PowerPoint** en ligne, hébergés en Suisse chez Infomaniak. Collaborez avec vos outils habituels tout en gardant un contrôle total sur vos données.

## Disponibilité

L'intégration Microsoft 365 est disponible avec :

- **kDrive Pro**
- **kSuite Business**
- **kSuite Enterprise**

:::note
Un abonnement Microsoft 365 est requis uniquement pour les entreprises. Pour les offres my kSuite et kSuite Standard, OnlyOffice est disponible gratuitement comme alternative.
:::

## Utiliser Microsoft dans un cloud 100% suisse

Les applications Microsoft Online (Word, Excel, PowerPoint) intégrées à kDrive sont **hébergées en Suisse** chez Infomaniak. Vous bénéficiez d'une compatibilité totale avec l'écosystème Microsoft, tout en gardant vos données sous juridiction suisse.

## Collaboration en temps réel

- **Co-édition** : plusieurs personnes modifient le même document simultanément.
- **Commentaires** : commentez vos documents et suggérez des modifications.
- **Outils de révision** : profitez de toute la puissance des outils de révision Microsoft Office.
- **Accès en déplacement** : consultez vos documents sur mobile, invitez vos contacts à lire, modifier ou réviser votre travail.

## Travail hors ligne

Utilisez **Microsoft Office sur vos ordinateurs** ou **OnlyOffice sur vos appareils mobiles** pour modifier et réviser vos documents hors ligne. Une fois en ligne, kDrive synchronisera automatiquement vos modifications.

## Sécurité et conformité

| Critère | Détail |
|---|---|
| Hébergement | Suisse, dans les datacenters Infomaniak |
| Conformité | RGPD, nLPD |
| Stockage | Triple sauvegarde sur 3 supports, 2 datacenters |
| Souveraineté | Hors Cloud Act, entreprise suisse indépendante |
| Partages | Contrôle précis des accès, boîtes de dépôt |

:::tip[Alternative gratuite]
kDrive intègre aussi OnlyOffice, une suite open source sans frais. Voir [OnlyOffice](../onlyoffice/).
:::
