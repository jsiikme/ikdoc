---
title: Gestion des fichiers
---

Ce guide explique comment organiser, modifier et gérer vos fichiers et dossiers dans kDrive.

## Structure des dossiers

kDrive organise vos fichiers en deux zones principales :

| Zone | Description |
|---|---|
| **Dossiers de l'organisation** | Dossier commun partagé avec tous les membres du kDrive. Accessible à tous les utilisateurs de l'Organisation. |
| **Mon dossier** | Espace privé personnel, accessible uniquement par vous. |

:::note
Les utilisateurs externes invités à un kDrive n'ont accès qu'aux dossiers partagés avec eux, via la section « Partagé avec moi ». Ils n'ont pas d'espace privé.
:::

## Importer des fichiers

Pour importer des fichiers dans kDrive :

1. Ouvrez kDrive dans votre navigateur ou l'app desktop.
2. Naviguez jusqu'au dossier de destination.
3. Cliquez sur le bouton **Importer** ou glissez-déposez les fichiers directement.
4. Les fichiers apparaissent immédiatement et sont synchronisés vers le cloud.

Depuis l'app mobile, vous pouvez également :
- Sauvegarder en temps réel les photos et vidéos de votre appareil.
- Numériser des documents avec l'appareil photo.

## Éditer une image en ligne

L'app Web kDrive intègre un éditeur d'images :

1. Ouvrez kDrive dans votre navigateur.
2. Ouvrez le fichier image concerné.
3. Cliquez sur le bouton **Modifier** en haut du document.
4. L'éditeur permet de :
   - Faire tourner l'image de 90° vers la droite ou la gauche.
   - Retourner (miroir) l'image horizontalement ou verticalement.
   - Recadrer l'image.
   - Modifier la luminosité et le contraste.
   - Créer et apposer une **signature** (offres payantes uniquement).
5. Sauvegardez en choisissant **créer une copie** ou **écraser** le fichier existant.

## Signer un document PDF

kDrive intègre un éditeur PDF pour signer en ligne :

:::note[Disponibilité]
La signature PDF est disponible avec : kSuite gratuit, Standard, Business, Enterprise, my kSuite, my kSuite+, kDrive Solo, Team, Pro.
:::

1. Ouvrez le document PDF dans kDrive.
2. Cliquez sur **Modifier** en haut du document.
3. Cliquez sur l'icône **Signature** dans la barre d'outils.
4. Cliquez sur **Ajouter une signature**.
5. Choisissez la méthode :
   - **Dessiner** à main levée avec la souris.
   - **Taper du texte** et choisir une police manuscrite.
   - **Importer une image** (scan de signature manuscrite).
6. Cliquez sur **Enregistrer**.
7. Cliquez sur la signature pour l'insérer dans le document.
8. Déplacez et redimensionnez la signature selon vos besoins.
9. Sauvegardez en choisissant **créer une copie** ou **écraser** le fichier existant.

:::tip
Vos signatures créées sont personnelles et réutilisables sur tous les kDrive auxquels vous avez accès.
:::

## Récupérer une ancienne version

kDrive fonctionne comme une machine à remonter le temps : vous pouvez à tout moment récupérer une ancienne version de vos documents.

1. Faites un clic droit sur le fichier concerné.
2. Choisissez **Versions** ou **Historique**.
3. Sélectionnez la version à restaurer.
4. Cliquez sur **Restaurer**.

## Exporter un e-mail vers kDrive

Vous pouvez enregistrer un e-mail directement sur votre kDrive au format `.eml` :

1. Ouvrez l'app Web Mail Infomaniak.
2. Ouvrez l'e-mail à sauvegarder.
3. Cliquez sur l'icône **Ajouter à kDrive** en haut du message.
   - Si l'icône n'est pas visible, cliquez sur le menu **⋮** > **Personnaliser les actions** pour l'ajouter.
4. Choisissez le kDrive et l'emplacement de sauvegarde.
5. Cliquez sur **Ajouter**.

L'e-mail enregistré peut être visualisé dans kDrive comme si vous le lisiez dans Mail directement.

## Ajouter une pièce jointe kDrive à un évènement Calendar

1. Créez un évènement sur l'app Web Calendar.
2. Cliquez sur **Insérer un lien kDrive**.
3. Choisissez le kDrive si nécessaire.
4. Naviguez et choisissez les fichiers à ajouter, ou importez de nouveaux documents.
5. Choisissez le type de lien : **public** ou **restreint**.
6. Cliquez sur **Ajouter**.

Les invités à l'évènement verront les liens dans la description.

## Rechercher dans kDrive

La recherche kDrive fonctionne non seulement sur les noms de fichiers, mais aussi dans le contenu de vos documents et images grâce à l'IA :

- **Recherche par nom** : tapez le nom du fichier ou dossier.
- **Recherche par contenu** : l'IA recherche du texte dans vos images, PDF et documents.
