# Plateformes

kMeet est disponible sur ordinateur, mobile et directement dans le navigateur. La solution utilise la technologie **WebRTC**, prise en charge par la plupart des navigateurs modernes.

## Applications de bureau

Des applications natives sont disponibles pour macOS, Windows et Linux. Elles offrent des fonctionnalités avancées non disponibles sur la version Web :

- **Dessin sur partage d'écran** et **tableau blanc collaboratif**.
- **Contrôle à distance** d'un appareil lors d'un partage d'écran.
- Meilleure stabilité en cas de problème avec l'app Web.

Téléchargement : [infomaniak.com/fr/applications/telecharger-kmeet](https://www.infomaniak.com/fr/applications/telecharger-kmeet)

## Applications mobiles

Des applications gratuites sont disponibles sur :

- **iOS** (iPhone / iPad) — App Store
- **Android** — Google Play

Vous pouvez créer ou rejoindre des réunions directement depuis votre smartphone.

!!! note "Limitation iOS"
    Le **partage d'écran n'est pas encore possible** avec l'app mobile iOS. Il est disponible sur l'app mobile Android et sur l'app Web/desktop.

## Version Web

Accessible sans installation via [kmeet.infomaniak.com](https://kmeet.infomaniak.com), la version Web fonctionne dans un navigateur.

!!! tip "Chiffrement E2E et navigateurs"
    Le chiffrement de bout en bout nécessite un navigateur basé sur l'architecture **Chromium** (Chrome, Edge, Opera, Brave, etc.) ou l'app desktop. Il n'est pas disponible sur mobile pour le moment. Voir [Sécurité](securite.md).
