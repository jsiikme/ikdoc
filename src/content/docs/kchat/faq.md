Questions fréquentes sur kChat, condensées depuis la FAQ officielle d'Infomaniak.

## kChat est-il plus sécurisé que les e-mails ?

Oui. kChat évite le spam et le phishing responsables de la majorité des problèmes de sécurité et des fuites de données en entreprise :

- Vous recevez uniquement des messages de vos collaborateurs ou des utilisateurs externes approuvés.
- Vous pouvez créer des [canaux privés](../canaux/) pour restreindre les informations sensibles.
- Vous contrôlez en permanence les droits d'accès des [membres](../membres/).

## Qu'est-ce qu'un canal ?

Un canal est un espace de communication dédié à un projet, un thème ou une équipe. Chaque organisation possède automatiquement un canal **Général**.

- **Canaux publics** : tous les utilisateurs peuvent les voir et les rejoindre pour plus de transparence.
- **Canaux privés** : restreignent le contenu sensible aux utilisateurs invités.
- **Messages personnels** : conversations directes entre deux ou plusieurs personnes, hors canaux.

Voir [Canaux](../canaux/) pour la gestion détaillée.

## Comment kChat sécurise-t-il les échanges ?

Infomaniak est une société de droit suisse certifiée ISO 27001 et ISO 9001 qui respecte le RGPD :

- Le Manager permet de vérifier l'activation de l'authentification à deux facteurs.
- Les données en attente et en transit sont chiffrées, de même que les sauvegardes.
- Les données sont hébergées en Suisse dans des datacenters gérés exclusivement par Infomaniak.
- L'indépendance économique et technologique place kSuite hors de portée du Cloud Act américain.

## Puis-je utiliser kChat avec des utilisateurs externes ?

Oui, kChat permet d'inviter un utilisateur externe comptabilisé comme un utilisateur **Guest**. Ce dernier sera invité à créer un compte Infomaniak s'il n'en possède pas un.

Voir [Membres et invités](../membres/) pour la procédure complète.

## Est-ce possible de commander kChat sans kSuite ?

Non, kChat est uniquement disponible avec kSuite.

## Peut-on importer l'historique de Teams, Slack ou d'autres solutions ?

Pas pour le moment. C'est l'occasion d'améliorer votre politique de communication interne.

## Sur quelles plateformes kChat est-il disponible ?

kChat est accessible via :

- **Web** : [ksuite.infomaniak.com/kchat](https://ksuite.infomaniak.com/kchat)
- **Desktop** : macOS, Windows, Linux (.AppImage)
- **Mobile** : iOS, Android

Voir [Plateformes](../plateformes/) pour les détails d'installation.

## Comment activer le mode sombre ?

Le mode sombre peut être activé manuellement ou automatiquement (basé sur les réglages système) depuis **Gérer mon compte** > **Apparence**. Voir [Plateformes](../plateformes/) pour la procédure.

## Comment traduire un message ?

- **À la lecture** : menu d'action **•••** > **Traduire** — le message traduit s'affiche pour vous uniquement.
- **À la rédaction** : utilisez [Euria](../ia/) pour traduire votre texte avant l'envoi.

## Comment planifier un envoi différé ?

Cliquez sur le chevron à droite du bouton d'envoi, puis choisissez le moment d'envoi. Sur mobile, appuyez longuement sur le bouton d'envoi.

:::note
L'envoi différé n'est pas disponible avec my kSuite / my kSuite+.
:::

## Comment démarrer un appel vidéo depuis kChat ?

Cliquez sur le bouton **Appeler** dans n'importe quelle conversation ou canal. L'appel utilise la technologie kMeet. Voir [Intégrations](../integrations/) pour les détails.
